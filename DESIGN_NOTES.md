# Train/Test Evaluation Design Notes (hardened gym)

- **Split.** Training: 24 public episodes (12 per experiment; `data/train_episodes.json`, simulator `data/tactile_sim.py`). Test: 384 held-out episodes (192 continuous, 192 contact-loss) defined only in `eval/test/evaluate_test.py` and rendered at test time by `eval/test/hidden_world.py`. Same families and parameter ranges, different seeds.
- **Interface.** Methods register `checkpoints/<dir>/predict.json`; the evaluators run the supplied procedure per episode on observation-only `.npz` inputs and score `poses.npy` / `loops.json`. Directories with artifacts but no spec are failed entries. No method names are hardcoded; `evaluate_test.sh` takes no arguments.
- **Independence.** `eval/train/` and `eval/test/` hold separate copies of the harness and frozen NormalFlow baseline; neither imports the other or `method/`. `eval/train` imports the public simulator from `data/`.
- **Scoring.** Per-axis rotation/translation MAE (paper Table IV), p95 geodesic/translation error, and false-loop excess (above a 2% allowance) per experiment. Failures, impossible values, duplicate relations or >10% false relations within either experiment give worst values everywhere. A provisional worst-case file is written first; the final file is written atomically.
- **Execution.** One numerical-library thread, one-core affinity, 7200 CPU seconds per episode including child processes, and no wall-clock deadline. Method commands can read public resources and their input but cannot read evaluator files or write outside their output directory; unsupported filesystem isolation fails closed. Scratch is private under `eval/<split>/scratch/`.
- **Recovery.** The audit can opt into private raw-output checkpoints under `eval/<split>/resume/`. Source/runtime/episode identities must match; all metrics and constraints are recomputed. No scalar score or saved verdict is trusted. Normal no-argument evaluation does not use these checkpoints.
- **Paired evidence.** All methods see the same inputs. The final better variant improves all eight error metrics and has a positive paired confidence interval. An independent reference and baseline rerun matches exactly. Exhaustive two-stage search still pays slightly on 400-frame instances: the requested efficiency-scale condition remains unmet.
