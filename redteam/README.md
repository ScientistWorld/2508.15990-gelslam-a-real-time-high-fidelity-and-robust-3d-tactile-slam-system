# Benchmark audit

Every trial has a `run.sh`. Run these inside the existing gym container; no installs or downloads are needed. `bash redteam/batch.sh` bundles all trials. The harness saves and restores the dataset, baseline source, checkpoints, and score files around every trial. It calls the restored hidden test as `bash scripts/evaluate_test.sh` with no arguments in a separate process. Nothing alters evaluator code, its environment, or its process. Candidate workers only import agent-visible data, baseline, and (in improve mode) method code.

Reference predictions reused by shortcuts are generated by `ref_seed_0`, not taken from hidden scores or pre-existing checkpoint caches. `reference_original/` is auditor-only context and is never read by a candidate. Failed evaluations save their exit status and log; an absent score file is not interpreted as a successful score. Numeric aggregate ranks use absolute coefficients, better directions, experiment weights, and per-metric standard deviations over the declared cohort. The external future cohort is unknown; dominance claims do not depend on that cohort.
