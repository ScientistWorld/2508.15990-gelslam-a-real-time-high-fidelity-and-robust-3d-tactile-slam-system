## Issues

The current reproduction intentionally uses a synthetic benchmark because the full real GelSLAM dataset is a 73 GB archive and the official release depends on ROS2/GTSAM reconstruction infrastructure. This is a data/scale substitution, not an algorithm substitution.

The first compute-container smoke job after the SE(3) rewrite failed before running the method because direct execution of `baseline/normalflow_baseline.py` did not include `/home/user` on Python's import path. The shell entrypoints now export `PYTHONPATH=/home/user:$PYTHONPATH` before invoking baseline, method, or evaluator scripts.

The second CPU smoke job completed but did not support the claim: NormalFlow scored 38.03 deg / 6.10 mm and scaled GelSLAM scored 38.27 deg / 6.44 mm. The failure was traced to a transform-convention mismatch: NormalFlow's image warp needs the inverse local-coordinate transform of the pose-graph measurement. The method now optimizes the pose-graph measurement but applies its inverse when warping reference tactile samples into target frames.

The next compute run after the convention fix executed the SE(3) pipeline successfully, reaching `method_runs`, but still failed the core claim: NormalFlow scored 3.91 deg / 5090.10 mm and GelSLAM scored 11.99 deg / 149.76 mm. The enormous translation numbers came from z drift in a synthetic orthographic benchmark where z/roll/pitch are not independently observable. The SE(3) implementation now pins those degenerate axes for this scaled data and avoids accepting adjacent keyframes as loop closures.

## Deviations From Paper

The reproduction target is a scaled synthetic substitute for the real GelSight long-horizon tracking dataset. The paper used physical GelSight Mini tactile videos with MoCap ground truth; this workspace evaluates generated tactile sequences with known synthetic ground truth and converts image-grid translation errors to millimeters using the GelSight Mini pixel pitch from the paper. Because the synthetic generator is orthographic and does not model calibrated indentation depth/tilt observability, z/roll/pitch are pinned during scaled NormalFlow optimization. The method is still expected to follow GelSLAM's computational procedure: tactile geometry extraction, NormalFlow tracking, keyframe selection, loop proposal, loop verification, and pose graph optimization.
