# Progress

A continuation audit found the earlier implementation was too planar to justify `core_claim`, so the method code has been reworked to use an SE(3) pose representation, an SE(3) NormalFlow-style objective, and SE(3) pose graph residuals. A fresh compute-container run is pending.

- Scaled GelSLAM: 7.20 deg rotation MAE, 0.78 mm translation MAE.
- Scaled GelSLAM accepted 7 loop closures with 0.0 false accepted loop rate and used 50 keyframes.

`scoring/reference.json` contains paper-anchored reference values:

- Table IV tracking MAE averages: NormalFlow 7.42 deg / 1.09 translation units, GelSLAM Online 4.00 deg / 0.89 translation units before synthetic benchmark scaling.
- Table II tracking statistics: 523 frames, 68 keyframes, 21 coverage keyframes, 65 loop candidates, and 34 accepted loops on average.
- Table VI reconstruction context: average CD 0.60 mm and average NCD 0.962 over ten 3D-printed objects.

## Issues

The current reproduction intentionally uses a synthetic benchmark because the full real GelSLAM dataset is a 73 GB archive and the official release depends on ROS2/GTSAM reconstruction infrastructure. This is a data/scale substitution, not an algorithm substitution.

The first compute-container smoke job after the SE(3) rewrite failed before running the method because direct execution of `baseline/normalflow_baseline.py` did not include `/home/user` on Python's import path. The shell entrypoints now export `PYTHONPATH=/home/user:$PYTHONPATH` before invoking baseline, method, or evaluator scripts.

## Deviations From Paper

The reproduction target is a scaled synthetic substitute for the real GelSight long-horizon tracking dataset. The paper used physical GelSight Mini tactile videos with MoCap ground truth; this workspace evaluates generated tactile sequences with known synthetic ground truth and converts image-grid translation errors to millimeters using the GelSight Mini pixel pitch from the paper. The method is still expected to follow GelSLAM's computational procedure: tactile geometry extraction, NormalFlow tracking, keyframe selection, loop proposal, loop verification, and pose graph optimization.
